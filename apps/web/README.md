# 知遇 AI 产品首页

使用 React、TypeScript、Vite、Tailwind CSS 4 和官方 shadcn/ui（Base UI）实现的外部产品首页。产品名“知遇 AI”为可替换的暂定名称。

## 本地运行

建议使用 Node.js 24 LTS。在本目录执行：

```bash
npm ci
npm run dev
```

打开 http://127.0.0.1:5173/ 。服务仅监听本机，端口占用时会报错，不会悄悄切换地址。

## 页面能力

- 响应式产品首页，包含产品介绍、简历分析演示、能力说明、工作流程和常见问题。
- 28 组虚构岗位示例，配有对应卡通头像，每 3 秒循环切换，淡出与淡入各 0.8 秒；也可通过下拉选择及上一组／下一组切换，查看简历依据和面试建议。
- 分析区提供重点摘要、双列卡片、线索时间轴和左右分栏四种排版，搭配七套柔和配色，28 组示例各有不同组合；依据与待核实项保留原意。
- 轮播提供暂停／播放按钮；打开菜单、查看弹窗或在工作台内操作键盘时暂时暂停，离开可见区域或切到其他页面时停止计时。减少动态效果模式下只保留手动切换。
- 工作台以底部为支点随滚动逐渐展平，点击或键盘聚焦不会强制回正；下拉菜单与卡片保持相同透视。蓝色描边加粗至 8 像素。
- 电脑工作台保留原有排版宽度，按窗口高度将外框、文字和内容整体等比例缩小，较矮窗口也能完整显示顶部切换栏和底部操作；手机保持上下阅读布局。
- 电脑鼠标移动可叠加轻微视差倾斜与跟随光晕，离开后恢复当前滚动角度。手机减小滚动动画幅度，关闭鼠标视差和光晕；减少动态效果模式下静态显示。
- 首页标题支持逐字散开与弹性归位：电脑鼠标掠过文字、手机轻点文字可触发；减少动态效果模式下保持静态，屏幕阅读器仍按完整标题朗读。
- 产品能力标题与三项介绍、底部体验区和页脚随滚动淡入淡出，反向滚动可重复呈现；页脚到达页面底部时完整显示，键盘聚焦及减少动态效果模式下保持可见。
- 常见问题左侧展示现有 28 个虚构人物头像，分三圈自动旋转，头像始终正立；背景透明、无外框及下方控制栏；支持悬停及键盘聚焦暂停，离开视口时暂停，减少动态效果模式下静态展示。滚动进入常见问题时，头像圈从左侧滑入淡入，四条问答从右侧依次滑入淡入，每项约 0.8 秒；再次滚入可重播，键盘聚焦及减少动态效果模式下立即完整显示，问答保持可用。
- 支持手机导航、键盘选择示例、弹窗焦点管理、减少动态效果偏好及跳转主要内容。
- 所有“体验”入口进入同一示例区，不要求注册、不接收真实简历。

当前分析内容为预设数据，没有接入模型、文件解析、登录或业务后台。页面明确标注演示边界；不使用虚构客户数量、准确率或效率承诺。

## 验证与构建

```bash
npm run lint
npm run build
npx playwright install chromium --only-shell
npm test
```

测试覆盖桌面和手机视口的入口、28 组岗位切换、三秒轮播与淡入淡出、暂停与循环、鼠标倾斜和光晕、倾斜菜单、依据与面试弹窗、键盘操作、常见问题、导航及横向溢出。截图保存在本地 `test-results/`，不纳入版本管理。

浏览器测试使用 Playwright 专用无界面浏览器和独立临时上下文，不读取日常浏览资料。

构建产物位于 `dist/`，可部署到静态网站服务。`npm run preview` 可在本机检查构建结果；它使用同一端口，需先停止开发服务。

## 修改入口

- `src/LandingPage.tsx`：页面结构、导航、营销文案和常见问题。
- `src/ResumeDemo.tsx`：示例选择与交互演示。
- `src/resume-samples.ts`：28 组虚构候选人、经历和分析材料。
- `public/avatars/`：用户提供的 28 张卡通头像，按编号与示例对应。
- `src/index.css`：品牌色、字体及 Tailwind 主题。
- `src/landing.css`：页面布局与响应式样式。
- `src/components/ui/`：官方 shadcn 组件，以及根据用户提供示例适配的 `container-scroll-animation.tsx` 滚动容器（framer-motion）和 `text-scatter.tsx` 标题动效（GSAP）。容器承载真实交互工作台，按内容自适应高度。
- `src/components/ui/scroll-fade.tsx`：可复用的滚动淡入淡出容器，用于产品能力介绍、体验区和页脚。
- `src/components/ui/avatar-orbit.tsx` 与同名 CSS：可复用头像轨道，接收 `members`（`id`、`name`、可选 `avatar`）、中心文字 `label` 和可选 `onSelect` 回调。不传回调时头像为展示内容；传入回调后成为可用键盘操作的选择按钮。图片加载失败时显示名字首字，保留无障碍名称。

遵循项目根目录 `../../AGENTS.md`。组件开发使用根目录的官方 shadcn Skill，按实际安装版本查询文档；已有内部系统模板不影响本目录技术栈。
