# 首页星球资源

2026-09-23 根据用户提供的 Orbit Delivery Hero React 组件接入，仅用于外部产品首页开场。

- 场景和人物动作代码：用户提供的单文件生成版，场景部分保留在 `src/components/ui/orbit-delivery/scene.tsx`。保留原来的球面运动、连续跑步、暂停招手、背包摆动及自适应分辨率；移除未使用的原型场景、物流导航和物流故事弹窗。
- `models/whimsical-world.glb` 和 `models/courier.glb`：来自用户组件指定的 [planet 资源仓库](https://github.com/fadeichev2121/planet/tree/b3f70fbf4b577845b1d9d5947c9410fb4d925dae/models)，固定版本 `b3f70fbf4b577845b1d9d5947c9410fb4d925dae`，通过 jsDelivr 下载到项目本地。
- `models/zhiyu-mascot.glb`：用户提供的 Tripo 生成知遇拟人化角色模型；原始文件 55 MB、约 100 万顶点。页面使用经 Draco 网格压缩、WebP 贴图压缩和网格简化后的版本（约 480 KB），保留模型外观并减少首次加载和设备显存压力。
- `models/surface.json`：直接解码用户组件内嵌的球面高度数据，128 × 65 个采样点；与上述星球模型配套，避免人物脚底穿过山体。
- `draco/draco_wasm_wrapper.js` 和 `draco/draco_decoder.wasm`：来自用户组件指定的 Google Draco `1.5.7` 解码器，下载地址为 `https://www.gstatic.com/draco/versioned/decoders/1.5.7/`；Apache 2.0 许可证保存在 `draco/LICENSE`。
- `brands/joincare-logo.webp` 与 `brands/livzon-logo.webp`：用户提供的健民集团与丽珠医药 Logo，用于地球同心轨道上的品牌节点。
- `brands/third-logo.png`：用户指定的远程 Logo 原图，来源为 `https://gcdn.meidianbang.cn/comdata/104552/202504/2025040114302328cde3.png`，下载到项目本地后用于第三条同心轨道，页面运行时不依赖该远程地址。

页面使用本地 `/orbit/` 资源，不加载原组件的远程字体，也不需要额外图库图片。星球、原有信使与知遇角色约 5.8 MB，三个品牌 Logo 约 54 KB，场景代码单独延迟加载；滚出视口或切换标签页时停止渲染。模型请求超时或失败、三维渲染不可用时显示中文提示及重新加载按钮，其他首页内容仍可使用。
