# AI 招聘系统内部工作台

采用完整的 [Ant Design Pro v6.0.3](https://github.com/ant-design/ant-design-pro/tree/v6.0.3) 工程，源提交为 `adfd44085738ca953573a13322c1ba84aca8b9e3`。保留原项目 MIT 许可证。

内部系统使用 Ant Design、ProComponents 和 Ant Design X；本目录供后续招聘业务开发使用。当前的看板、列表、表单、登录、权限与对话页面均为模板演示，不代表招聘功能已经完成。

## 启动

推荐 Node.js 24（至少 24.15.0）与 npm；也支持 Node.js 22.22.2 以上的 22 系列及 Node.js 26 以上版本。在本目录执行：

```sh
npm ci
npm run dev
```

打开 `http://127.0.0.1:8000`。本地模拟管理员账号为 `admin`，密码为 `ant.design`；普通演示账号为 `user`，密码相同。这些是公开模板的虚构账号，不是系统正式凭据。

如果当前电脑默认使用 Node.js 25，可执行 `npx --yes --package=node@24 -c 'npm run dev'`，使用 Node.js 24 启动而不改动系统默认版本。

开发服务仅监听本机。更换电脑后使用 `npm ci` 按锁文件安装，不单独将 ProComponents 替换成默认的旧版。

## 验证

```sh
npm run lint
npm test
npm run build
```

`npm run preview` 可查看生产构建的静态页面，但不提供本地模拟登录接口。正式身份认证、数据权限、招聘接口与模型服务仍需后续开发。

## 本项目调整

- 保留完整后台布局、路由、页面模板和 Ant Design X 对话示例，默认简体中文。
- 当前 Umi 开发代理没有把 HOST 传给监听接口。启动前会自动应用一处监听地址补丁；上游代码结构改变时停止启动并提示复核，不静默放开访问。构建继续使用官方 utoopack。
- 以官方工程的依赖组合为基础，应用兼容范围内的安全修复，并保留 `.npmrc` 安装设置。具体版本以本项目锁文件为准；ProComponents 3 使用与 antd 6 配套的预发布版本。
- 移除模板作者的统计标识、公开演示后端代理与公共模型地址。业务请求使用同源 `/api/`；模型请求使用同源 `/api/chat/completions`。
- 开发环境的 AI 消息只得到固定的本地演示回复，不调用模型、不执行招聘操作。界面会明确标注演示状态。
- 模拟接口只用于本机开发，不可用作正式认证服务；不要输入真实简历或候选人信息。部分模板图片、字体仍来自上游公共静态资源。
- 不导入上游自动发布流程及英文提交钩子，提交遵循项目根目录的中文协作约定。

官方 `antd` 技能已安装在项目根目录 `.agents/skills/antd/`，来源和校验记录在 `skills-lock.json`。编写组件前使用本项目的 `npx antd info` 和 `npx antd demo` 查询实际版本，修改后运行 `npx antd lint ./src --format json`。

弃用检查发现官方模板仍在 12 个示例文件中使用旧 `List`（32 处提醒），另有 14 处静态反馈 API 的使用提醒，本次安装保留这些原始示例；它们在当前版本仍可用，后续招聘列表应按实际需求使用 `Listy` 或 `ProTable`，组件内的反馈使用 `App.useApp()`。注册示例的 `Popover.overlayStyle` 已改为当前推荐的 `styles.root`。

`config/routes.ts` 管理页面路由，`config/defaultSettings.ts` 管理布局主题，`src/pages/` 保存业务页面。外部产品页由后续任务单独设计。
