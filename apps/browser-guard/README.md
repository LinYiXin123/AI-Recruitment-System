# 页面安全提示 Chrome 扩展

这是一个只对你手动启用的网站生效的提示型扩展。它根据浏览器窗口尺寸变化，提示“可能有停靠式开发者工具打开”，并保存最近 50 条不含页面内容的本地提示记录。

它不关闭开发者工具、不阻止访问，也不能保护浏览器已经下载到客户端的源码。涉及权限、密钥、计费、数据写入等关键逻辑，仍应放在服务端校验。

## 本机加载

1. 在此目录执行 `npm ci`，再执行 `npm run build`。
2. 打开 Chrome 的“扩展程序”页面，开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本目录下的 `dist` 文件夹。
4. 打开需要提示的网站，点击浏览器工具栏中的“页面安全提示”，再开启“保护此网站”。浏览器会仅为该网站请求访问权限。

在扩展的“管理网站与提示记录”页面，可以随时移除某个网站及其对应权限，也可以清空本地记录。

## 隐私与工作方式

- 网站必须由你逐个开启；扩展没有“所有网站”的常驻权限。
- 本地只保存网站来源（例如 `https://example.com`）和提示时间；不保存完整网址、页面内容、表单输入或账号信息。
- 尺寸变化也可能来自缩放、浏览器侧边栏或系统界面，因此提示应只作为排查线索，不能据此判定用户在调试。
